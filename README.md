# 🤖 HOK Community Moderation Bot

## Setup Guide

### 1️⃣ Install Node.js
Download from: nodejs.org (v18 or higher recommended)

### 2️⃣ Create your Discord Bot
- Go to discord.com/developers → New Application
- Go to "Bot" → Reset Token → **Copy your token**
- Enable Message Content Intent under Privileged Gateway Intents

### 3️⃣ Get your Gemini API Key (FREE)
- Go to: makersuite.google.com
- Sign in with Google → Create API Key → Copy your key
